RB Stems Plus 1.1: Stems Cache now works on its own, with rekordbox's own stems model too.

## What's new

- **Stems Cache works with either model.** Until now it saved only the stems of the Stems Plus
  model. Now it also saves the stems of rekordbox's own model, so you get much faster reloads
  without Stems Plus too. rekordbox still gets its own model's stems, exactly as before: only the
  next loads come from the cache.
- **Each feature on its own.** **Install Stems Plus** and **Install Stems Cache** are separate
  buttons. **Uninstall Stems Plus** puts rekordbox's model back and leaves Stems Cache alone, with
  no password.
- **A clearer Stems Cache light.** When it's yellow, hold the pointer over it: it says why, for
  example a STEMS Engine it doesn't support yet.
- **Other accounts on the same Mac:** if Stems Cache is already installed from another account,
  **Install Stems Cache** turns it on in yours, with no password.

## Updating

RB Stems Plus offers the update when you open it (**RB Stems Plus › Update RB Stems Plus**).

Already using Stems Cache? Click **Reinstall** once after updating: until then, Stems Cache saves
only the Stems Plus model's stems. As with every update, macOS asks you to allow RB Stems Plus
again the next time it changes rekordbox.

## Install

Paste this in Terminal and press Return:

```sh
curl -fsSL https://github.com/Gabe-LS/rbstemsplus/releases/latest/download/bootstrap.sh | bash
```

The app opens and walks you through the rest. Installing Stems Cache takes about a minute.

## What you need

- A Mac. Tested on macOS 26 Tahoe on an Apple Silicon Mac.
- rekordbox 7.2.17, 7.2.18 or 7.2.19, with STEMS working (turned on at least once).
- About 1.5 GB of free space, and an administrator account for Stems Cache.
