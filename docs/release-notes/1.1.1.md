RB Stems Plus 1.1.1: Stems Plus is now called Demucs v4.

## What's new

- **Stems Plus is now called Demucs v4,** the name of the model it puts in rekordbox. The light
  and the buttons (**Install**, **Reinstall** and **Uninstall Demucs v4**) say Demucs v4. The app
  is still called RB Stems Plus, and Stems Cache keeps its name.
- **Nothing else changes.** It's the same model, and Stems Cache keeps the stems it has saved.

## Updating

RB Stems Plus offers the update when you open it (**RB Stems Plus › Update RB Stems Plus**).
There's nothing to reinstall. As with every update, macOS asks you to allow RB Stems Plus again
the next time it changes rekordbox.

## Install

Paste this in Terminal and press Return:

```sh
curl -fsSL https://github.com/Gabe-LS/rbstemsplus/releases/latest/download/bootstrap.sh | bash
```

The app opens and walks you through the rest. Installing Stems Cache takes about a minute.

## What you need

- A Mac. Tested on macOS 26 Tahoe on an Apple Silicon Mac.
- rekordbox 7.2.17, 7.2.18 or 7.2.19, with STEMS working (turned on at least once).
- About 1.5 GB of free space, and an administrator account for Stems Cache.

## Need help?

Most problems have a quick fix in the
[troubleshooting page](https://github.com/Gabe-LS/rbstemsplus/blob/main/docs/troubleshooting.md).
If that doesn't help, open RB Stems Plus, choose **Help › Create Report** and open an issue
(you need a free GitHub account).
