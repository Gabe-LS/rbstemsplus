The first release of RB Stems Plus: a different stems model and much faster reloads for
rekordbox's STEMS, on the Mac. Free and open source.

## What you get

- **Stems Plus: a different stems model.** It swaps rekordbox's stems model for Demucs v4, the
  newer version of Meta's open source separation model that rekordbox's own is based on. The two
  split some sounds differently, so listen and keep the one you prefer. The rekordbox app itself
  isn't changed.
- **Stems Cache: much faster reloads.** rekordbox separates a track again every time you load
  it. Stems Cache keeps the stems it already made, so the next time they load much faster,
  without separating the track again. It needs Stems Plus, and it changes one file inside
  rekordbox, so macOS asks you to allow it.

You can install both, or just Stems Plus. Both work offline once installed.

When rekordbox updates itself, Stems Cache switches off. A small background helper,
RB Stems Plus Watcher, notices and offers to put it back with one click.

## Install

Paste this in Terminal and press Return:

```sh
curl -fsSL https://github.com/Gabe-LS/rbstemsplus/releases/latest/download/bootstrap.sh | bash
```

The app opens and walks you through the rest. Installing Stems Cache takes about a minute.

## What you need

- A Mac. Tested on macOS 26 Tahoe on an Apple Silicon Mac.
- rekordbox 7.2.17, 7.2.18 or 7.2.19, with STEMS working (turned on at least once).
- An administrator account, and about 1.5 GB of free space.

## Uninstall

Open RB Stems Plus and click **Uninstall RB Stems Plus Completely**. rekordbox goes back to
exactly how it was, and the app deletes itself and everything it saved. You can also remove just
one feature with **Uninstall Stems Cache** or **Uninstall Stems Plus**.

## Safe to try

- **Signed releases.** The install command and the app check every file against a signed list
  before using it.
- **Nothing is sent anywhere.** No tracking, no accounts.
- **rekordbox can always go back.** Pioneer's original files are kept, and uninstalling puts
  them back. Reinstalling rekordbox from rekordbox.com works too.
- Your music and your rekordbox library are never touched.

## Need help?

Most problems have a quick fix in the
[troubleshooting page](https://github.com/Gabe-LS/rbstemsplus/blob/main/docs/troubleshooting.md).
If that doesn't help, open RB Stems Plus, choose **Help › Create Report** and open an issue
(you need a free GitHub account).
