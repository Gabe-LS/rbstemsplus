RB Stems Plus 1.4: rebuilt inside, and more careful with rekordbox's own stems model.

## What's new

- **Rebuilt inside, the same outside.** RB Stems Plus now runs on one shared core, the same one
  its coming Windows version uses. The window, the menus and the dialogs look and work as in
  1.3: nothing should change for you. If something does, please report it.
- **The window keeps updating while a dialog is open.** Progress, the lights and the lists now
  keep moving under every dialog, the password sheet and "Permission needed" included, where 1.3
  froze them.
- **rekordbox's own stems model is never lost.** If macOS can't read rekordbox's stems model or
  its folder for a moment, RB Stems Plus now stops and says so, instead of taking the model for
  missing. It never replaces rekordbox's model without a saved copy, and never puts the saved
  copy back over a model it couldn't read.
- **A model folder that is a link.** If rekordbox's model folder is a link to another place,
  RB Stems Plus doesn't install its model there, and uninstalling stops and keeps the saved copy
  of rekordbox's own model (you can still choose **Remove RB Stems Plus Anyway**), instead of
  deleting it with the rest.
- **The saved copy of rekordbox's model stays with Remove RB Stems Plus Anyway**, also when its
  folder was renamed with other capitals or a saved copy can't be read for a moment.
- **Stems saved on a drive:** an uninstall that stops halfway always leaves the folder
  recognisable, also when its marker file was renamed with other capitals, so RB Stems Plus
  finds the folder again and can finish later. A folder that can't be read is left as it is.
- **It says what couldn't be deleted.** A file RB Stems Plus can't check is reported as not
  deleted, instead of gone. If the stems left on this Mac after you chose a drive can't all be
  read, they are tried again at the next start instead of being taken for deleted.
- **If RB Stems Plus can't move itself to the Trash** at the end of an uninstall, it now says so
  and stays open.
- **One version number for Mac and Windows.** From 1.4 both versions share one number. A release
  that changes only the Windows version doesn't replace RB Stems Plus on your Mac, so macOS
  doesn't ask you to allow it again; **About** shows the release's version.

## Updating

RB Stems Plus offers the update when you open it (**RB Stems Plus › Update RB Stems Plus…**). As
with every update, macOS asks you to allow RB Stems Plus again.

Once updated, RB Stems Plus asks to update Stems Cache too (**Update**, with your password, or
**Not Now**), and macOS asks you to allow RB Stems Plus again when it updates Stems Cache.

## Install

Paste this in Terminal and press Return:

```sh
curl -fsSL https://github.com/Gabe-LS/rbstemsplus/releases/latest/download/bootstrap.sh | bash
```

The app opens and walks you through the rest. Installing Stems Cache takes about a minute.

## What you need

- A Mac. Tested on macOS 26 Tahoe on an Apple Silicon Mac. Older versions, from macOS 12, should
  work but are untested. Intel Macs should work too, untested; preparing playlists needs Apple
  silicon.
- rekordbox 7.2.17, 7.2.18 or 7.2.19 (tested with 7.2.19), with STEMS working (turned on at least
  once).
- About 1.5 GB of free space, and an administrator account for Stems Cache. Prepared stems take
  about 13 to 16 MB per minute of music, depending on the model (AAC files up to twice that).
