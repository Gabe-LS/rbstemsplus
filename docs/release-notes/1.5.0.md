RB Stems Plus 1.5.0 brings Demucs v4, Stems Cache and Prepare to Windows for the first time.

## What's new on Windows

- **Demucs v4** gives you another way to split a track into vocals, drums, bass and the rest.
  You can switch back to rekordbox's own model any time.
- **Stems Cache** saves the stems rekordbox makes, with either model. Load the same track
  again and rekordbox can reuse its stems. The cache defaults to **This PC**. Use **Change…**
  next to *Stems Cache location* in **Settings…** to choose a supported external drive.
- **Prepare** makes stems for supported playlist tracks ahead of time. Open it with
  **View › Prepare** and see your prepared playlists on the **Status** tab. Demucs v4 Prepare
  runs on the CPU only. Prepare accepts supported audio that decodes at 44.1 kHz. On rekordbox
  builds with verified sample rate conversion, it also accepts MP3 at 16 to 48 kHz, mono or
  stereo WAV, FLAC, AIFF and Apple Lossless at 22.05, 48, 88.2, 96 and 192 kHz, and AAC-LC at
  some rates from 16 to 48 kHz. FLAC files can end in `.flac` or `.fla`.
  Prepare skips 20-bit and 32-bit Apple Lossless (ALAC) and files at other sample rates.
  See [Which files can Windows prepare?](https://github.com/Gabe-LS/rbstemsplus#which-files-can-windows-prepare).
  The files Prepare accepts on Mac don't change.
- The Windows app has a light appearance only.

## Several versions of rekordbox on Windows

rekordbox installs new versions alongside older ones. Stems Cache works in every supported
version you have installed. One install and one Windows administrator prompt cover all versions
that are ready to install.

When several versions are installed, **Manage** shows a row for each one. The row says **On**,
**Ready to install**, **Unsupported**, **Needs repair** or **Couldn't verify**. **Put Back
Pioneer's File** restores the original file in each version that needs it. **Uninstall Stems
Cache** removes Stems Cache from each affected version.

If you already use Stems Cache, RB Stems Plus checks new versions automatically. When a new
version is ready, it offers to add Stems Cache. Choose **Install Now**, **Remind Me Later** or
**Don't Ask Again for This Version**. If several versions are ready, one prompt can cover them
and offers **Don't Ask Again for These Versions**.

## What's changed on Mac

- **More careful with stems saved on a drive.** If the cache folder moves to a different drive
  while Stems Cache is checking it, Stems Cache refuses that folder and rekordbox can separate
  the track as usual. Stems Cache also checks the same copy of the model throughout, even if
  the model file is being replaced.
- **More careful with rekordbox's own model.** If RB Stems Plus can't record which STEMS Engine
  a saved model belongs to, it stops and says so. If a copy saved by version 1.0 can't be moved
  to the new layout, the app leaves it in place and stops before restoring another copy.
- **Changes wait for rekordbox's installer.** If it starts while RB Stems Plus is downloading
  files, the app asks you to let it finish before continuing. It also checks before putting
  rekordbox's files back.
- **Reinstall Now does only what the reminder named.** After a rekordbox update, a reminder
  about Demucs v4 no longer reinstalls Stems Cache too, so it doesn't ask for your password.
- **A stems folder it can't read isn't shown as empty.** Settings says *couldn't measure* next
  to **Clear Saved Stems**, and when you change the location the message still says that the
  stems saved on this Mac will be deleted.
- **Cancel keeps your settings.** If you've moved rekordbox and cancel when asked to remove its
  saved files, Stems Cache remembers your choice for rekordbox's own model.
- **The app update finishes sooner after the window closes.** The updater checks more often
  whether the previous copy has quit.
- **Problem reports hide names and paths more reliably.** The title and the short summary that
  go into the GitHub issue hide those details before shortening the text.

## Updating

When the app offers an update, choose **RB Stems Plus › Update RB Stems Plus…**. You'll also
be asked to update Stems Cache if there's a new version. On Mac, updating Stems Cache asks for
your password and macOS asks you to allow RB Stems Plus again.

## Install

On Windows, open PowerShell from the Start menu as a normal user. Paste this line and press Enter.

```powershell
irm https://github.com/Gabe-LS/rbstemsplus/releases/latest/download/bootstrap.ps1 | iex
```

On Mac, paste this line in Terminal and press Return.

```sh
curl -fsSL https://github.com/Gabe-LS/rbstemsplus/releases/latest/download/bootstrap.sh | bash
```

The app opens and walks you through the rest.

## What you need

- **Windows.** Windows 11 version 22H2 or later, x64 or ARM64, .NET Framework 4.8.1 or later,
  and rekordbox 7.2.19 or 7.2.20 for Stems Cache. Installing Stems Cache asks for an administrator's
  permission.
- **Mac.** macOS 12 or later. Tested on macOS 26 Tahoe on an Apple Silicon Mac. Older macOS
  versions and Intel Macs are untested. Preparing playlists needs Apple silicon. Stems Cache
  supports rekordbox 7.2.17, 7.2.18, 7.2.19 and 7.2.20 and needs an administrator account.
  Allow about 1.5 GB of free space for the app and its files, plus room for saved stems.
- **Both.** Turn on STEMS in rekordbox at least once to download its STEMS Engine. Choose
  **Prioritize sound quality** in **Preferences › Extensions › STEMS**.
