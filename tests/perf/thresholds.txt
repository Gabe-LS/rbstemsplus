# and helper's GP, baseline B0):
#   metric  stat  limit  floor  tag  baseline
# Owner decided, 2026-11-12: "This whole speed test thing is becoming a joke. One thing is to
# ensure we are not losing performance, another is spending 20 hours testing the speed to the
# millisecond." Only what a user could notice is gated: a slowdown counts only when it is BOTH
# over 10% AND over the floor, 20 ms for a time, 20 MB for memory (about what anyone reading
# Activity Monitor next to the app's 30-90 MB would notice, far above footprint's own jitter).
# Every other number both sides measure is printed for information and never blocks; a change
# within 25% of its allowance is printed BORDERLINE for a human to judge. Rows are written before
# B is measured: tightening is free, loosening needs the owner.
# P16.children (tests/perf/stats.py) counts every child the app reaps in a Create Report round,
# LocationMonitor's pgrep runs set off by the report's temporary folder included, and sums
# overlapping children twice: P16.own (P16 less it) is biased low, the same way in A and B.
